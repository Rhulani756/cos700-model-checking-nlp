Root-cause candidates to weigh against the trace (root_cause) — name the
one the evidence supports, or say the evidence doesn't distinguish:
- an unvalidated input used directly as a divisor
- a divisor computed from a subtraction/difference that can reach zero
- a divisor whose value depends on a branch or loop outcome the trace
  shows taking an unexpected path

evidence / execution_path: trace the divisor's value from where it's
computed or received to the line of the division/modulo. Only describe
its origin (input, computation, prior branch) if the trace actually shows
that origin.

suggested_changes: phrase each item as something to verify (e.g. "check
what value this expression takes when the two operands are equal"), not
as a specific guard to add. Never state the exact conditional to insert.

example_fix: only populate if the trace shows clearly how the divisor
reaches zero. Illustrate the *pattern* (e.g. a generic zero-check guard)
with placeholder names, not the student's own variables wired into a
working guard. Otherwise leave empty and reflect the gap in confidence.

check_your_understanding: ask what value the divisor takes on the failing
path, not about division by zero in general.
